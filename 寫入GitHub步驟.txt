寫入GitHub步驟

1. 把變動「掃進」準備上傳的清單中：
git add . 

2. 為變動貼上標籤，寫下你做了什麼：
git commit -m "寫下你做了什麼"

把這個存檔點送到 GitHub
git push

結合輸入
git add . && git commit -m "update" && git push
------------------------------------------
開工

抓進度
git pull

進環境
source venv/Scripts/activate

如果你改了好幾個檔案，覺得通通都不要了，想直接同步雲端最新進度：

# 第一步：把所有本地改動通通「抹掉」
git reset --hard HEAD

# 第二步：安心抓取雲端更新
git pull

強制對齊雲端，想完全以 GitHub 雲端為準：
確保本地知道遠端分支的最新狀態
git fetch origin
強制覆蓋本地分支
git reset --hard origin/main
上述指令只會處理 Git 追蹤的檔案。如果你想把本地新建、但不在遠端倉庫裡的「雜物」資料夾或檔案一併刪除：
git clean -fd

強制恢復到最後一次提交：(改動後想復原並清除提交提醒)    
git reset --hard HEAD
