寫入GitHub步驟

1. 把變動「掃進」準備上傳的清單中：
git add . 

2. 為變動貼上標籤，寫下你做了什麼：
git commit -m "寫下你做了什麼"

把這個存檔點送到 GitHub
git push

結合輸入
git add . && git commit -m "update" && git push
------------------------------------------
開工

抓進度
git pull

進環境
source venv/Scripts/activate

如果你改了好幾個檔案，覺得通通都不要了，想直接同步雲端最新進度：

# 第一步：把所有本地改動通通「抹掉」
git reset --hard HEAD

# 第二步：安心抓取雲端更新
git pull

如果你連本地的 Commit 紀錄都覺得亂掉了，想完全以 GitHub 雲端為準：
# 強制讓本地 main 分支「對齊」雲端的 origin/main
git reset --hard origin/main
